# Kuro Japan

A soft-black Japanese-inspired Omarchy theme with Fuji-slate shadows, warm
ivory text, dusk copper, and vermilion accents.

## Install

```bash
omarchy theme install https://github.com/R7rainz/kuro-japan.git
omarchy theme set kuro-japan
```

## Included

- Soft charcoal surfaces with a pure-black top bar
- Mount Fuji, Lawson with Mount Fuji, and Tokyo Tower wallpapers
- Transparent Mount Fuji unlock art with a small smoke plume
- Generated terminal, shell, editor, browser, and system-tool colors through `colors.toml`

## Wallpaper controls

```bash
omarchy theme bg next
```

The palette lives in `colors.toml`; `shell.toml` keeps the top bar black.
